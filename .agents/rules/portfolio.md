# Regras do portfólio profissional

Aplicar estas orientações ao trabalho de portfólio neste workspace, preservando regras específicas dos projetos.

- Usar a skill `portfolio-architect` para diagnóstico, estratégia, construção e revisão do portfólio.
- Retomar pelo arquivo `portfolio-context/estado.md`; diferenciar tarefas planejadas de resultados confirmados.
- Sustentar afirmações profissionais com fontes. Não inventar métricas, autoria, senioridade ou validações.
- Manter documentos pessoais em `portfolio-private/`, excluído do Git. A exclusão não é controle de acesso: ler somente os materiais autorizados e revisar informações derivadas antes de publicar.
- Preferir evidências de engenharia proporcionais ao cargo alvo. Não aumentar complexidade apenas para impressionar.
- Usar comandos compatíveis com o ambiente detectado. Informar testes executados e verificações pendentes.
- Preservar alterações existentes. Realizar somente operações externas já autorizadas; não mudar configurações de aprovação para viabilizar uma tarefa.

- Não copiar ou reimplementar funcionalidades de projetos profissionais reais. Usá-los somente para identificar competências abstratas. Antes de conceber ou implementar um projeto, ler `portfolio-context/references/originalidade.md` e seguir a revisão de originalidade prevista ali.
